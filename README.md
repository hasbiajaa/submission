# SeSepedaaa Dashboard ✨

## Setup Environment - Anaconda
```
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
```

## Setup Environment - Shell/Terminal
```
pipenv install
pipenv shell
pip install -r requirements.txt
```

## Run streamlit app
```
cd dashboard
streamlit run dashboard.py
```
